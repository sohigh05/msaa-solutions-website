# MSAA Solutions

Laman korporat MSAA Solutions menggunakan HTML, CSS dan JavaScript.

Laman web: https://sohigh05.github.io/msaa-solutions-website/

## Halaman

- `index.html` — halaman utama.
- `tentang.html` — profil syarikat, maklumat CIDB dan carta organisasi.
- `perkhidmatan.html` — senarai perkhidmatan.
- `hubungi.html` — maklumat perhubungan, borang WhatsApp, Google Maps dan Waze.

## Buka pada laptop

Buka fail `index.html` menggunakan pelayar web. Fail CSS, JavaScript dan imej berada dalam folder `assets` dan perlu dikekalkan bersama fail HTML.

## Kemas kini GitHub Pages

GitHub Pages diterbitkan daripada cabang `main`, folder akar repositori. Perubahan yang dihantar ke `main` akan dikemas kini pada laman secara automatik.

Kod dibahagikan mengikut bahagian dan dilengkapi dengan komen ringkas bagi memudahkan pembacaan.
